# HRIPOP Media — Next.js

A responsive Next.js App Router website built from the supplied HRIPOP content brief and cinematic homepage reference.

## Local development

```sh
pnpm install
pnpm dev
```

Then visit `http://localhost:3000`.

## Production check

```sh
pnpm build
pnpm start
```

The enquiry form currently provides complete front-end validation and confirmation. Connect the submit handler in `app/page.jsx` to the chosen email, CRM, or form endpoint for production delivery.
